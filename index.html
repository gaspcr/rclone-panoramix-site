rclone panoramix

rclone panoramix is a personal, non-commercial configuration of the open-source rclone command-line tool. It is used by a single researcher to copy astronomical data products (reduced spectral data cubes, coadds, quality-control plots and reports) from a university computing cluster to his own Google Drive, so that collaborators can access them.

What it does

  • Uploads files that the owner selects from the cluster to folders in the owner's Google Drive.
  • Lists and checksums those folders to verify that transfers completed correctly.
  • Renames or moves files the owner previously uploaded, at the owner's request.

It is not a public service: there is no sign-up, no other users, and no web interface. The Google OAuth client exists only so that rclone on the cluster can authenticate as the owner.
