Privacy policy

Last updated: 14 October 2026

This policy describes how rclone panoramix (a personal configuration of the open-source rclone tool, see home page) handles Google user data.

Who uses it

The application is used only by its owner, to access the owner's own Google Drive. It does not offer accounts to, or collect data from, any other person.

Data accessed

With the Google Drive scope granted by the owner, rclone reads file and folder metadata (names, sizes, checksums, modification times) and creates, updates, renames or moves files in the owner's Drive, only when the owner runs an rclone command.

Storage

The OAuth access and refresh tokens are stored only in the rclone configuration file on the owner's cluster account. No Google user data is stored on any server operated for this application; there is no such server. Files are transferred directly between the cluster and Google Drive.

Sharing

Google user data is not sold, shared with third parties, used for advertising, or used to train any machine-learning model. No analytics or tracking is used.

Limited Use

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, and by deleting the rclone configuration on the cluster.

Contact

Open an issue in this site's GitHub repository.
